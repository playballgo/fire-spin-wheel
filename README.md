# 🎡 火花輪盤 (Spark Spinner) - 華麗的線上抽籤與隨機決定器

[![GitHub Pages](https://playballgo.github.io/HouDe/SPIN.html)

**火花輪盤 (Spark Spinner)** 是一個專為解決「選擇困難症」而設計的網頁互動工具。無論是小組抽籤、午餐決定、活動遊戲或是命運對決，這款工具結合了流暢的 Canvas 物理旋轉特效與華麗的煙火動畫，讓每一個決定瞬間都充滿儀式感。

---

## 🌟 為什麼選擇「火花輪盤」？ (Key Features)

* **極致視覺體驗**：內建高品質煙火粒子系統，當結果揭曉時，畫面將綻放華麗煙火慶祝。
* **自定義選項**：支援多行文字輸入，輕鬆設定無限數量的抽籤項目。
* **雙重旋轉模式**：
    * **命運旋轉**：享受 6 秒鐘擬真的物理加速與減速旋轉。
    * **快速結果**：針對追求效率的使用者，一鍵立即得知答案。
* **SEO 與響應式設計**：
    * 優化的 HTML5 Meta 標籤，讓搜尋引擎（如 Google）輕鬆找到。
    * 支援手機、平板與桌機，隨時隨地開啟抽籤。
* **語音播報 (TTS)**：中獎結果自動透過合成語音讀出，增加互動趣味。

---

## 🛠️ 技術細節 (Technical Overview)

身為注重性能與系統穩定性的開發者，本專案在輕量化的同時兼顧了高效能表現：
* **Core**: 純 JavaScript (Vanilla JS) 編寫，不依賴任何外部重型框架。
* **Rendering**: 使用 HTML5 Canvas API 進行輪盤繪製與 60FPS 粒子動畫。
* **Performance**: 優化動畫循環，確保在低功耗設備上也能流暢運行。

## 🚀 快速開始 (Quick Start)

1.  **造訪網頁**：[點此開啟火花輪盤](https://playballgo.github.io/HouDe/SPIN.html)。
2.  **輸入選項**：在右側文字方塊輸入你想抽籤的內容（每行一個）。
3.  **旋轉決定**：點擊「命運旋轉」按鈕。
4.  **慶祝時刻**：等待輪盤停下，享受煙火與中獎播報。
